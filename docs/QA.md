# 拾光相册 v1.0.0 验收记录

本记录对应 Windows x64 发行版。只使用公开测试样例和生成的测试图片、音频；个人相册没有参与测试。

## 已完成

- 九项相册数据与播放顺序测试通过：多相册隔离、重命名、排序、封面、复制原件、音乐持久化、移除不改动原文件、同名不同内容、重复导入、损坏图片、取消导入、递归文件夹、磁盘空间不足及索引写入失败。短暂文件占用会重试，持续失败仍保留原索引。
- 磁盘不足通过注入 ENOSPC 模拟，不填满用户的磁盘；写入失败通过隔离测试目录模拟。失败后已有索引保持可读，未完成的媒体副本被清理。
- 真实 Electron 桌面测试通过 JPG、PNG、WebP、GIF、BMP、AVIF、旋转 EXIF JPEG，以及损坏 HEIC 的逐文件错误提示。
- libheif 官方 example.heic、PhotoPrism iPhone 15 Pro 和 libheif issue 1213 的 iOS 18 样例，均在打包程序中转换为 JPEG、缩略图并离线播放成功，显示方向已核对。
- 十种动效逐项完成切换；暂停与继续、四十次快速切换、二十四次重叠切换、减少动态效果、音乐循环与同步暂停、音量、静音、桌面全屏已经检查。开始放映会停止整理页的音乐试听。
- 最终安装包安装成功，实际启动通过 36 项检查，跨进程重启通过 37 项检查；卸载测试确认相册数据保留。程序在 Windows 11 x64 验收，Windows 10 未在独立机器上实测。
- 屏蔽 HTTP / HTTPS 后全流程运行成功；相册数据、照片、音乐、排序与设置跨重启保存。
- 示例界面截图已经保存，第三方许可、HEIC 组件对应源代码随程序附带。
