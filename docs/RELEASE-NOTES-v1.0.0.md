# 拾光相册 v1.0.0

Windows 10 / 11、64 位离线电子相册。

- 多相册管理，批量导入、文件夹导入、拖入照片、缩略图、拖动排序与封面。
- JPG、PNG、WebP、GIF、BMP、AVIF、HEIC / HEIF，HEIC 原件保留、后台转换。
- 三种放映氛围、十种动效、主题随机动效避免连续重复。
- 顺序或随机播放、循环、暂停恢复、全屏、3–30 秒停留时间。
- 每个相册一首背景音乐，支持循环、音量和静音，与照片同步暂停恢复。
- 本机副本、原子保存与索引备份。重新打开回到相册首页。

本次先交付本机文件，GitHub 发布暂缓。便携版可直接使用，安装版可创建快捷方式。程序未数字签名。校验值见 `SHA256SUMS.txt`，使用与数据备份说明见 `拾光相册-使用说明.html` 或 `使用说明.md`。

源码采用 MIT，第三方组件使用各自许可。发行不包含个人照片或音乐；仅提供六张公开授权的示例照片。

首版没有云同步、自动更新、视频相册、HDR 显示和音乐编辑功能。
